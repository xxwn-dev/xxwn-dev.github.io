- **Problem**

- Link: [Valid Palindrome 2](https://leetcode.com/problems/valid-palindrome-ii/description/)
- Tags: #Algorithm #TwoPointer #Level/Easy

- **Logic & Approach**

- **How to Solve:** 양 끝에서 포인터를 좁히며 비교하다가 문자가 다를 때 왼쪽을 하나 건너뛴 부분 또는 오른쪽을 하나 건너뛴 부분이 팰린드롬인지 확인한다.
- **Key Point:** 최대 한 번의 기회를 논리합 연산으로 처리하는 헬퍼 함수를 이용한다.

- **Java Solution**

```java
 	  class Solution {
    	    	private boolean isPalindrome(String s, int i, int j){
    	      	while(i < j){
    	            if(s.charAt(i) != s.charAt(j)){
    	            	return false;
    	            }
    	            i++;
    	            j--;
    	          }
    	        	return true;
    	      }
    	      public boolean validPalindrome(String s) {
    	          int left = 0;
    	        	int right = s.length()-1;
    	        	
    	        	while(left < right){
    	          	if(s.charAt(left) != s.charAt(right)){
    	              	return isPalindrome(s, left+1, right) || isPalindrome(s, left, right-1);
    	              }
    	            	left++;
    	            	right--;
    	          }
    	        	return true;
    	      }
    	  }
```    

- **Analysis**

- Time: $O(N)$
- Space: $O(1)$

- **Review**

- 오른쪽, 왼쪽 모두 시도하는 것 -> Greedy
- while-loop 중첩하는 대신 헬퍼 함수를 사용 하지만 재귀 형태로 바꿔서 쓸 수 있다.
```java
 	  class Solution {
    	      public boolean validPalindrome(String s) {
    	          return checkPalindrome(s, 0, s.length() - 1, 0);
    	      }
    	  
    	      private boolean checkPalindrome(String s, int left, int right, int deletedCount) {
    	          // 이미 1번을 초과해서 지웠다면 더 이상 진행 불가
    	          if (deletedCount > 1) {
    	              return false;
    	          }
    	  
    	          while (left < right) {
    	              if (s.charAt(left) != s.charAt(right)) {
    	                  // 문자가 다를 때 두 가지 선택지:
    	                  // 1. 왼쪽 문자 무시하고 다음 확인 (deletedCount + 1)
    	                  // 2. 오른쪽 문자 무시하고 다음 확인 (deletedCount + 1)
    	                  return checkPalindrome(s, left + 1, right, deletedCount + 1) ||
    	                         checkPalindrome(s, left, right - 1, deletedCount + 1);
    	              }
    	              left++;
    	              right--;
    	          }
    	  
    	          return true;
    	      }
    	  }
```
